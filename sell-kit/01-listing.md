## English (Flippa / CodeCanyon / Gumroad)

**Title:** Complete Arabic RTL E-commerce Store — Moroccan Traditional Clothing (Next.js + Prisma + PostgreSQL) with Full Admin Panel

**Description:**

A complete, production-ready e-commerce platform built for the Moroccan/Arabic market, selling traditional clothing (Djellaba, Kaftan, Takchita, accessories). 100% Arabic RTL with premium gold/ink design.

**What's included:**
- Full storefront: home, products with search & category filters, product detail (size/quantity/buy-now/WhatsApp), cart, COD checkout, customer account
- Complete admin panel: sales dashboard, orders management (status/return/refund), products with variants (S–XXL + stock), customers, settings
- Real database: Prisma + PostgreSQL (SQLite for local dev) with 12 products, 4 categories, reviews, coupons, orders, subscribers
- Security: JWT httpOnly cookies, 2FA (TOTP), admin login
- Analytics: product-view tracking + admin stats (AOV, COD refusal rate, low-stock alerts)
- Newsletter with city capture, in-app notifications, editable store settings (WhatsApp number, shipping, FAQ)
- Arabic SEO: meta titles, descriptions, Open Graph, dynamic images
- 30 passing Jest tests

**Stack:** Next.js 14 (App Router) · TypeScript · Tailwind CSS 3 · Prisma 6 · PostgreSQL · JWT · TOTP

**Runs on:** Vercel (static + serverless) / any Node.js host.

**Deployed live demo:** https://mose-ecommerce.vercel.app
**Admin demo:** https://mose-ecommerce.vercel.app/admin — `admin@mose.ma` / `admin1234`

**What the buyer gets:** full source code (GitHub repo transfer), Vercel project, PostgreSQL database, admin access, documentation, seed data, and setup support.

**Use cases:** launch a Moroccan traditional-clothing store, white-label for clients, or extend into a general Arabic RTL e-commerce base.
