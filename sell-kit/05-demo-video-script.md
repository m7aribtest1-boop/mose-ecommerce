# Demo Video Script (3 minutes) — for buyers

> Record once (OBS free), upload privately to Loom/YouTube unlisted. This is the single strongest conversion tool (ChatGPT: "show, don't just describe").

**Golden rule:** by the end of 3 minutes the buyer must think: *"This isn't a mockup. It's software."*

---

## 0:00–0:20 — Storefront
- Open https://mose-ecommerce.vercel.app
- Slow pan: hero (Moroccan photo + serif headline), brand story, categories grid.
- Voiceover: *"A complete, production-ready Arabic RTL storefront, built for the Moroccan market."*

## 0:20–0:45 — Search / Filter
- Type "قفطان" in search → results with real product photos.
- Open a category (الجلابة) and a product.
- VO: *"Search, categories, product cards — all real, all functional."*

## 0:45–1:10 — Product → Size → Cart → COD Checkout
- On a product page: choose a size (S–XXL), set quantity.
- Add to cart, open cart, go to checkout.
- Fill a test order, choose **الدفع عند الاستلام (COD)**.
- VO: *"Size variants, cart, and full COD checkout — the way Moroccans actually buy."*

## 1:10–1:40 — Customer account
- Show login/register flow (brief) + order history view.
- VO: *"Customer accounts with order tracking."*

## 1:40–2:30 — Admin dashboard
- Go to https://mose-ecommerce.vercel.app/admin (log in).
- Pan: dashboard KPIs (sales, orders, AOV), analytics charts, low-stock alerts.
- VO: *"A real admin panel — not a mockup. KPIs, analytics, everything a store owner needs."*

## 2:30–2:50 — Orders / Inventory / Customers
- Open Orders → show status workflow (pending → shipped → delivered).
- Open Products → show variants + stock per size.
- Open Customers (empty/demo) — mention.
- VO: *"Full order management, per-variant inventory, returns/refunds."*

## 2:50–3:00 — Stack + Transfer
- End card: Next.js 14 · TypeScript · Prisma · PostgreSQL · Vercel — **CI passes, 30+ tests**.
- VO: *"Clean code, documented, transferable. GitHub + Vercel + database handover with a step-by-step checklist. Serious buyers, let's talk."*
